# Cheatsheet

This document contains guidelines for things like track width for different types of circuits.

## Tracks
- **0.127mm**
  - Ethernet
    - TRD Pairs



- **0.13mm**


#### Ethernet
- **0.127mm**
  - TRD Pairs

#### HDMI
- **0.13mm**
  - Hot Plug
  - I2C
  - CEC
- **0.127mm**
  - Clock Pair
  - Data Pairs

#### CSI
- **0.3mm**
  - 3.3v
  - GND
- **0.13mm**
  - I2C
- **0.127mm**
  - PHY


#### USB
- **0.13mm**
  - OTG
- **0.127mm**
  - Rx
  - Tx
  - D

#### MicroSD
- **0.3mm**
  - GND (1x 0.45/0.2)


#### USB-C
- **0.5mm**
  - +5v (3x 0.45/0.2)
  - GND (1x 0.45/0.2)
- **0.147mm**
  - Data pair
- **0.13mm**
  - CC2
- **0.127mm**
  - CC1
